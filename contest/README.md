# منصة مسابقات المحقق العلمي — الإصدار 2

منصة مسابقات علمية قابلة لإعادة الاستخدام لكل الصفوف المتوسطة (الأول والثاني والثالث) ولأعوام قادمة.

| الملف | الوظيفة |
|---|---|
| `index.html` | صفحة الطالب (قائمة المسابقات المفتوحة، أو مسابقة محددة عبر `?c=`) |
| `admin.html` | لوحة المعلم: المسابقات، النتائج، التقارير والشهادات، الأعوام والحذف |
| `apps-script/Code.gs` | الخادم (Google Apps Script + Google Sheets) |
| `config.js` | ضع فيه رابط الخادم ليصبح رابط الطلاب قصيرًا |
| `templates/mohaqiq-ads.json` | قالب «المحقق العلمي — الإعلانات المضللة» الجاهز |

## التركيب (مرة واحدة)
1. افتح script.google.com ← مشروع جديد، وألصق `apps-script/Code.gs` كاملًا وغيّر `ADMIN_KEY` إلى رمز سري.
2. شغّل الدالة `setup` مرة واحدة ووافق على الصلاحيات (يُنشأ جدول البيانات تلقائيًا في Drive).
3. نشر ← نشر جديد ← تطبيق ويب ← التنفيذ باسم: أنا ← الوصول: أي شخص.
4. افتح `admin.html` وأدخل رابط تطبيق الويب والرمز.
5. (اختياري) ضع الرابط في `config.js` لتقصير روابط الطلاب.

عند تعديل `Code.gs` لاحقًا: نشر ← إدارة عمليات النشر ← تعديل ← إصدار جديد (يبقى الرابط كما هو).
